# MMMonitor 0.3.0

The first public release of MMMonitor brings glanceable, local-only Apple Silicon monitoring to the macOS menu bar.

## Highlights

- configurable multi-metric menu-bar readout with compact, balanced, network, and full presets
- optional CPU sparkline, stable-width values, metric ordering, and app icon
- CPU and per-core activity, memory and swap, network interfaces, local volumes, and battery health
- top processes, thermal state, uptime, load averages, and selectable live history
- independent settings window that remains interactive while metrics refresh
- optional sustained-threshold notifications with cooldowns and quiet hours
- point-in-time JSON diagnostics exported only when requested
- native arm64 build with no accounts, analytics, privileged helper, or administrator requirement

## Install

Download `MMMonitor-0.3.0-arm64.zip` and its matching checksum file. Place them together and verify the archive before opening it:

```sh
shasum -a 256 -c MMMonitor-0.3.0-arm64.zip.sha256
```

Unzip the archive, move `MMMonitor.app` to `/Applications`, then Control-click the app and choose **Open** the first time if macOS offers that option.

This release is ad-hoc signed and is not notarized. Managed Macs may require IT approval; do not bypass workplace security policy. MMMonitor itself does not need administrator access.

See the [architecture and IT review](../ARCHITECTURE.md) for data sources, permissions, and privacy boundaries.
