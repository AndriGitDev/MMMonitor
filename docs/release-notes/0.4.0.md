# MMMonitor 0.4.0

MMMonitor 0.4.0 adds an opt-in 24-hour view while keeping historical storage small, transparent, and entirely local. It also expands the Battery card with the raw capacity details already exposed by supported Mac batteries.

## Highlights

- selectable one-day CPU, memory, and network graphs
- optional history persistence between launches
- bounded storage using at most 1,440 one-minute aggregate samples
- explicit Clear History action with confirmation
- per-interface network history in the one-day view
- battery design and full-charge capacity details in mAh where available
- battery capacity fields included in user-exported diagnostic snapshots

## Privacy and storage

High-resolution history remains memory-only. One-day persistence is disabled by default and writes only minute averages collected while MMMonitor is running. Saved samples stay in `~/Library/Application Support/MMMonitor/history-v1.json`, are automatically limited to the most recent 24 hours, and can be removed from Settings at any time.

MMMonitor does not inspect network traffic or destinations and does not transmit history or diagnostics.

## Install

Download `MMMonitor-0.4.0-arm64.zip` and its matching checksum file. Place them together and verify the archive before opening it:

```sh
shasum -a 256 -c MMMonitor-0.4.0-arm64.zip.sha256
```

Unzip the archive, move `MMMonitor.app` to `/Applications`, then Control-click the app and choose **Open** the first time if macOS offers that option.

This release is ad-hoc signed and is not notarized. Managed Macs may require IT approval; do not bypass workplace security policy.

See the [architecture and IT review](../ARCHITECTURE.md) for data sources, permissions, persistence, and privacy boundaries.
