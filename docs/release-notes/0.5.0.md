# MMMonitor 0.5.0

MMMonitor 0.5.0 brings MacQueen's complete Keep Awake workflow into MMMonitor's existing menu-bar app and fixes the optional CPU sparkline across macOS menu-bar appearances.

## Highlights

- a reorderable Keep Awake dashboard card with no second menu-bar item
- 30-minute, one-, two-, four-, eight-hour, and indefinite sessions
- Mac-only mode, which allows the display to sleep
- Mac-plus-display mode, which keeps both awake
- live active-session countdown in MMMonitor's existing menu-bar label
- mode switching during an active session without resetting its end time
- automatic stop at the end of timed sessions
- immediate power-assertion cleanup on stop, expiry, mode change, and app termination
- a CPU sparkline that remains visible on dark, light, and translucent menu bars

## Permissions and behavior

Keep Awake uses public macOS IOKit power-management assertions. It requires no administrator access, installs no helper or daemon, and remains active only while MMMonitor is running and the user-started session is active. Closing a MacBook lid or explicitly choosing Sleep can still put the Mac to sleep.

## Install

Download `MMMonitor-0.5.0-arm64.zip` and its matching checksum file. Place them together and verify the archive before opening it:

```sh
shasum -a 256 -c MMMonitor-0.5.0-arm64.zip.sha256
```

Unzip the archive, move `MMMonitor.app` to `/Applications`, then Control-click the app and choose **Open** the first time if macOS offers that option.

This release is ad-hoc signed and is not notarized. Managed Macs may require IT approval; do not bypass workplace security policy.

See the [architecture and IT review](../ARCHITECTURE.md) for data sources, permissions, persistence, and privacy boundaries.
