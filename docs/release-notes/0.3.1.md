# MMMonitor 0.3.1

MMMonitor 0.3.1 adds quick, carefully scoped DNS cache maintenance to the existing network dashboard.

## Highlights

- one-click **Flush DNS** action in the Network card
- visible progress and success feedback
- quiet handling when administrator authorization is cancelled
- clear feedback if macOS cannot complete the operation
- no accounts, analytics, network services, or persistent privileged helper

## Security

DNS flushing is performed only after an explicit click and the normal macOS administrator authorization dialog. MMMonitor runs the fixed system commands `/usr/bin/dscacheutil -flushcache` and `/usr/bin/killall -HUP mDNSResponder`; it does not insert user input into the command or leave a privileged process installed.

All monitoring behavior remains unprivileged and local-only.

## Install

Download `MMMonitor-0.3.1-arm64.zip` and its matching checksum file. Place them together and verify the archive before opening it:

```sh
shasum -a 256 -c MMMonitor-0.3.1-arm64.zip.sha256
```

Unzip the archive, move `MMMonitor.app` to `/Applications`, then Control-click the app and choose **Open** the first time if macOS offers that option.

This release is ad-hoc signed and is not notarized. Managed Macs may require IT approval; do not bypass workplace security policy.

See the [architecture and IT review](../ARCHITECTURE.md) for data sources, permissions, and privacy boundaries.
